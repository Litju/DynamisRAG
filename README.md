# DynamisRAG

Evaluation-first RAG platform for auditable retrieval and evidence-grounded AI.

**This repository is being bootstrapped.** The project foundation -- Python 3.12
and uv layout, a FastAPI application shell, PostgreSQL 18 and OpenSearch 3
through Docker Desktop, migrations, and lint/type/test gates -- lands in
`main` via the tracked pull request for
[RES-130](https://linear.app/alignerr-cmj/issue/RES-130/bootstrap-dynamisrag-repository-and-local-runtime).

Until that pull request merges this file is the whole repository. See the pull
request for the full setup instructions.
